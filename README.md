# Les Trails des Conquérants

Site vitrine statique pour la course des 6 heures de Sainte-Suzanne.

## Pages

- Accueil
- Présentation & inscription
- Photos/Vidéos
- Revue de presse
- Partenaires
- Résultats
- Contact

Le site est volontairement sans backend : les inscriptions, résultats, règlement, Facebook et contact pointent vers les liens externes existants.
